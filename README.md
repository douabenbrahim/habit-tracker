# Habit Tracker 📱

A mobile application developed with **Java and SQLite** to help users build consistent habits and track their daily progress.

## 📌 About the Project

Habit Tracker is an Android application that allows users to record their habits, log completed activities, and monitor their progress over time.

## ✨ Features

- **Habit Management:** Add and manage personal habits.
- **Activity Tracking:** Record completed habits and daily activities.
- **Streak Tracking:** Follow consecutive days of habit completion.
- **Local Data Storage:** Store habit-related data using SQLite.

## 🛠️ Technologies Used

- **Language:** Java
- **Database:** SQLite
- **Platform:** Android
- **User Interface:** XML layouts

## 📂 Project Structure

- `app/src/main/java/` — Java source code.
- `app/src/main/res/layout/` — XML layout files.
- `app/src/main/res/drawable/` — Drawable resources.
- `app/src/main/res/values/` — Application resources, such as strings and styles.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync and resolve the project dependencies.
4. Run the application on an Android emulator or compatible device.
